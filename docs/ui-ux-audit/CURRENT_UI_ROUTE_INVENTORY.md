## 3. Detailed Structural Anomalies & Redundancy Register

### 3.1. Triple-Rendered Counterparty Subsystems
1. **Customers:** Available at `/customers`, `/invoices?tab=customers`, and `/masters?tab=customers`. All three views expose customer master data with slightly diverging filter controls and navigation buttons.
2. **Vendors:** Available at `/vendors`, `/expenses?tab=vendors`, and `/masters?tab=vendors`.
3. **Products & Services:** Available at `/products` and `/masters?tab=products`.
4. **Bank Accounts:** Configurable inside `/bank-transfers?tab=accounts`, `/settings?tab=bank`, and `/masters?tab=bank_accounts`.

### 3.2. Orphaned Backend Services & Actions Lacking User Interfaces
1. **Loan & Facility Management (`LoanService`):**  
   - Implemented in `services/loan.service.ts`.
   - Server actions implemented in `app/(dashboard)/finance/loan-actions.ts` (`createLoanAction`, `recordLoanRepaymentAction`, `deleteLoanRepaymentAction`).
   - Page route `app/(dashboard)/finance/page.tsx` consists entirely of `redirect('/bank-transfers')`.
   - **Impact:** Financial administrators cannot view or service loans via the application UI.
2. **Disaster Recovery & Backup Management (`BackupRestoreService`):**  
   - Implemented in `services/backup-restore.service.ts`.
   - Server actions implemented in `app/(dashboard)/admin/backup-actions.ts` (`triggerBackupAction`, `listBackupsAction`, `verifyBackupChecksumAction`, `runHistoricalDryRunAction`).
   - Page route `app/admin/page.tsx` consists of `redirect('/dashboard')`.
   - **Impact:** Manual backups and SHA-256 verification cannot be performed through the web browser.
3. **Advanced Role & Permission Builder (`UserManagementClient.tsx`):**  
   - Located at `app/(dashboard)/users/UserManagementClient.tsx` (552 lines, fully equipped with custom role creator, permission checkboxes, department filters, and user view modal).
   - `app/(dashboard)/users/page.tsx` renders `UsersRolesClient.tsx` (a simplified 100-line table).
   - **Impact:** System administrators are locked into basic role assignment and cannot use the built-in custom role builder.

### 3.3. Authorization Gaps
- **Standalone Profit & Loss (`/profit-loss`):** Enforces `requireAdmin()`. However, the central Reports Hub (`/reports?category=financial`) allows `FINANCE`, `ACCOUNTANT`, and `AUDITOR` to view financial statements. This causes an unexpected 403 / redirect to dashboard when an accountant tries to view the standalone P&L statement.

### 3.4. Dead Controls
- **Customer Statement Print Action:** Located at `app/(dashboard)/customers/[id]/statement/page.tsx:L41-L47`. Contains a styled `<button>` element with text "Print Statement" but **zero `onClick` event handler**.
- **Global Search Pill in Header:** Located at `components/Header.tsx:L85-L91`. Displays "Search vouchers, accounts, invoices... ⌘K" as a static `<div>` without click listeners or keyboard shortcut handlers.
